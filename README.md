# DeepSeek 纯聊天模式

以 DeepSeek 网页版界面呈现的 DeepSeek Harness 纯聊天插件。

- 右下角「纯聊天」进入，右上角「退出纯聊天」返回 Harness；Esc 也可以退出。
- 左侧栏列出当前 Profile 的顶层对话，可搜索、切换、开始「新对话」。
- 消息流只显示用户文本、图片、模型回答与（可折叠的）思考过程；工具调用、步骤、上下文注入和运行过程都不出现在界面上。
- 输入框支持 Enter 发送、Shift+Enter 换行；生成中按钮变为停止。
- 输入区提供**模型切换**、**深度思考**、**联网搜索**和**图片附件**。
  - 模型切换来自 Harness 的模型目录；选择会写回当前对话，之后的新消息使用新模型。
  - 深度思考切换当前模型的 reasoning effort（有多个思考等级时可用）；这是真实请求参数，不是显示开关。
  - 联网搜索开启后，先用 Harness 的 web 搜索能力检索，再把结果作为上下文交给模型；Host 搜索命令未加载时会退回“提示模型先调用 web_search”的方式。
  - 图片附件支持 PNG / JPEG / WebP / GIF；图片会随消息发送给模型。图片识别取决于所选模型（例如支持视觉的 4.1flash）。
- 左下角切换浅色 / 深色。
- 会话列表与消息都来自 Session 日志本身；切换会话或刷新页面后仍可继续，未发送的草稿按对话分别保存。
- 刷新页面后从右下角「纯聊天」进入；不会自动打开上次的浮层，避免异常时把整个 Harness 挡住。

## 安装

1. 解压 ZIP，得到 `deepseek-pure-chat` 文件夹；打开后应**直接**看到 `package.json`、`client.js`、`index.js`、`cordis.patch.yml`。如果看到里面还套着一层 `deepseek-pure-chat`，请使用里面那一层。
2. 打开 DeepSeek Harness 左侧的 **Plugins（插件）** 页面，点右上角 **添加插件（Add plugin）**。
3. 在 **包名或地址** 输入框里粘贴解压后文件夹的**完整本地路径**（不是 ZIP 文件的路径），例如：
   `C:\Users\你的用户名\Downloads\deepseek-pure-chat`
   也可以在“安装引导和示例”里点“本地目录”示例，再把示例路径替换成实际路径。
4. 点 **安装（Install）**。如果提示该插件已安装旧版本，请先在插件页卸载旧版本，再安装这个文件夹。
5. 安装完成后按页面提示**重启 DSH**；重启后在“已安装插件”里确认 **DeepSeek 纯聊天模式** 已启用。
6. 打开 Harness 后点右下角 **纯聊天** 浮标进入。
   - 本插件没有安装脚本，不会要求运行构建脚本。
   - 本地目录安装通常以链接方式引用这个文件夹；安装后**不要删除或移动它**，否则插件会失效，需要重新安装。
   - 对方需要与当前 DSH 版本相近的环境（本插件按 `0.2.2-rc.3` 的 Client API 编写）。

也可以在命令行/工具里用 `plugin_manager` 的 `install_bundle`，目标填这个文件夹的绝对路径。

## 说明

- 这是展示层的“纯聊天”：不会禁用 Agent 的工具。模型调用工具时，调用过程不显示，最终回答照常出现；如果某一轮只有工具调用而没有文字回答，这一轮会显示一条提示。
- 图片附件目前只支持图片；普通文件上传尚未接入 Harness 的文件上传回执。
- 联网搜索需要 Harness 已配置可用的 web 搜索 provider；没有配置时模型会收到“搜索不可用”的说明。搜索结果是外部内容，作为参考资料而不是指令注入。
- “深度思考”只在模型声明了多个思考等级时可用；切换模型或思考等级会写入当前对话的模型选择。
- 想使用 4.1flash：先在 Harness 的 **设置 → 模型 / Models** 里配置该 provider 和模型；然后在纯聊天的模型菜单里选择它。模型是否接受图片由 Harness 的模型能力信息决定。
- 新建对话会沿用最近一段对话的工作目录；若该目录不可用，会退回默认工作目录。
- 插件安装或更新后，浏览器端脚本需要刷新页面才会换成新版本。
- 如果某个对话正在等待你的确认（工具审批、提问等），纯聊天界面顶部会出现「回到 Harness 处理」按钮，点击会切回该对话的 Harness 界面。
